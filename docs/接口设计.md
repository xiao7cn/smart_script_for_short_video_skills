# 闪创工厂 · 接口设计

| 项目 | 内容 |
| --- | --- |
| 文档版本 | v1.0 |
| 业务基地址 | `/api` |
| Harness 基地址 | `http://127.0.0.1:8790`（内网，仅 Server 可访问） |
| 编码 | UTF-8，`Content-Type: application/json` |
| 认证 | `Authorization: Bearer <token>` |

---

## 1. 通用约定

### 1.1 统一响应

HTTP 状态码一律 200（除鉴权 401、越权 403、限流 429、服务异常 500），业务结果看 `code`。

```json
{ "code": 0, "message": "ok", "data": { }, "requestId": "d3f1…" }
```

分页：

```json
{ "code": 0, "message": "ok",
  "data": { "records": [], "total": 128, "page": 1, "size": 20 } }
```

### 1.2 错误码

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 400 | 参数校验失败 |
| 401 | 未登录或令牌过期 |
| 403 | 无权访问该资源 |
| 404 | 资源不存在 |
| 429 | 触发限流 |
| 500 | 服务内部错误 |
| 1001 | 手机号格式不正确 |
| 1002 | 验证码错误或已过期 |
| 1003 | 验证码发送过于频繁（60 秒内） |
| 1004 | 当日验证码发送次数超限 |
| 1005 | 微信授权失败 |
| 1006 | 账号已停用 |
| 2001 | 人设档案不存在 |
| 3001 | 额度不足 |
| 3002 | 生成条数超出范围（1~20） |
| 3003 | 任务不存在 |
| 3004 | 任务已结束，不可重复操作 |
| 3005 | 未选择任何参数且候选池为空 |
| 4001 | 该平台不支持自动取件，请上传录屏 |
| 4002 | 取件失败，请检查浏览器登录态 |
| 4003 | 转写失败，未检测到可用 ASR 后端 |
| 4004 | 原文过短，无法拆解 |
| 5001 | 洗稿与原文连续重合超限 |
| 5002 | 洗稿自检存在低于 8 分的项 |
| 5003 | 洗稿缺少必需段落 |
| 6001 | 充值套餐不存在 |
| 6002 | 订单不存在或状态不允许 |
| 7001 | 模型场景不存在 |
| 7002 | Harness 不可用 |

### 1.3 幂等

写接口支持可选请求头 `X-Request-Id`。生成、洗稿、拆解、充值四类接口会以 `(user_id, request_id)` 去重，重复提交返回首次结果。

## 2. 账号

### 2.1 发送验证码

`POST /api/auth/sms/code`

```json
{ "phone": "13800001111" }
```

```json
{ "code": 0, "data": { "sent": true, "cooldown": 60, "devCode": "123456" } }
```

`devCode` 仅在非生产环境返回，用于原型里「演示验证码」的展示。

### 2.2 手机号登录（首登即注册）

`POST /api/auth/sms/login`

```json
{ "phone": "13800001111", "code": "123456" }
```

```json
{ "code": 0, "data": {
  "token": "eyJhbGci…", "expiresIn": 7200, "firstLogin": true,
  "user": { "userId": 1, "nickname": "138****1111", "account": "13800001111",
            "via": "phone", "avatar": null },
  "credits": 20
} }
```

### 2.3 微信一键登录

`POST /api/auth/wechat/login`

```json
{ "code": "wx_auth_code", "phoneCode": "可选，获取手机号用" }
```

响应同 2.2，`user.via = "wechat"`，`user.account` 为 openid。

非微信环境下，开发模式允许传演示 code（形如 `wx_demo_xxx`）直接登录。

### 2.4 当前用户

`GET /api/auth/me` → 同 2.2 的 `user` + `credits` + `stats`

```json
{ "code": 0, "data": {
  "user": { "userId": 1, "nickname": "微信用户", "account": "wx_ab12cd", "via": "wechat" },
  "credits": 18,
  "stats": { "total": 23, "generated": 8 }
} }
```

### 2.5 登出

`POST /api/auth/logout` → `data: null`

## 6. 文案生成

### 6.1 提交生成

`POST /api/scripts/generate`

```json
{
  "sel": { "…同 5.1…" },
  "count": 5,
  "promptOverride": "用户手改后的提示词，可空"
}
```

```json
{ "code": 0, "data": {
  "taskNo": "9f2c7a1e5b8d4c3f9a0e1d2b3c4f5a6b",
  "accepted": 5,
  "requested": 5,
  "creditsHold": 5,
  "creditsBalance": 13,
  "message": null
} }
```

- `count` 超出剩余额度时按剩余额度受理，`accepted < requested`，`message` 说明「额度仅够生成 N 条」。
- 额度为 0 直接返回 `3001`。
- `count` 不在 1~20 返回 `3002`。

### 6.2 查询任务

`GET /api/tasks/{taskNo}`

```json
{ "code": 0, "data": {
  "taskNo": "9f2c…", "type": "SCRIPT_GENERATE", "status": "RUNNING",
  "total": 5, "doneCount": 2, "failCount": 0,
  "items": [
    { "idx": 0, "status": "SUCCESS", "scriptId": 1201 },
    { "idx": 1, "status": "SUCCESS", "scriptId": 1202 },
    { "idx": 2, "status": "RUNNING", "scriptId": null },
    { "idx": 3, "status": "PENDING", "scriptId": null },
    { "idx": 4, "status": "PENDING", "scriptId": null }
  ],
  "creditsSettled": 2,
  "errorCode": null, "errorMsg": null,
  "startedAt": "2026-09-05 18:20:11", "finishedAt": null
} }
```

`status` 取值：`PENDING` / `RUNNING` / `SUCCESS` / `PARTIAL` / `FAILED` / `CANCELLED`。

前端轮询间隔 2 秒，终态停止。

### 6.3 任务列表

`GET /api/tasks?type=SCRIPT_GENERATE&page=1&size=20`

### 6.4 取消任务

`POST /api/tasks/{taskNo}/cancel` — 仅 `PENDING` / `RUNNING` 可取消，未开始的子项退额度。

```json
  { "scene": "SCRIPT_REWRITE",  "sceneName": "文案重写",  "…": "…" },
  { "scene": "VIDEO_EXTRACT",   "sceneName": "爆款拆解",  "…": "…" }

```

### 11.2 更新某场景

`PUT /api/admin/ai-models/{scene}`

```json
{ "provider": "openai", "modelId": "gpt-4o", "temperature": 0.7,
  "maxTokens": 4096, "thinking": "off", "baseUrl": null,
  "apiKeyEnv": "OPENAI_API_KEY", "maxSteps": 1, "timeoutMs": 180000,
  "enabled": true, "remark": "重写换 GPT 试效果" }
```

改动**下一次调用即生效**，无需重启。脚本生成与文案重写是两个独立场景，互不影响。

### 11.3 可用模型清单

`GET /api/admin/ai-models/catalog` — 透传 harness 上报的 provider 与模型清单，便于前端做下拉。

```json
{ "code": 0, "data": [
  { "provider": "deepseek", "ready": true,
    "models": ["deepseek-chat", "deepseek-reasoner"] },
  { "provider": "openai", "ready": false, "models": ["gpt-4o", "gpt-4o-mini"] }
] }
```

`ready=false` 表示该 provider 的环境变量密钥未配置。

## 12. Harness 契约（Server ↔ Agent）

这一节是**与 harness 实现无关**的内部契约。换 pi 为 deepseek harness 或自研 harness，只要满足本契约，Java 侧零改动。

### 12.1 执行

`POST /v1/harness/run`

```json
{
  "requestId": "5b8d4c3f9a0e1d2b",
  "scene": "SCRIPT_GENERATE",
  "model": {
    "provider": "deepseek",
    "modelId": "deepseek-chat",
    "temperature": 0.8,
    "maxTokens": 4096,
    "thinking": "off",
    "baseUrl": null,
    "apiKeyEnv": "DEEPSEEK_API_KEY"
  },
  "systemPrompt": "你现在是一名资深的短视频文案写手…",
  "messages": [ { "role": "user", "content": "【人设】…【选题】…请输出正文" } ],
  "tools": [],
  "maxSteps": 1,
  "timeoutMs": 180000
}
```

成功：

```json
{
  "requestId": "5b8d4c3f9a0e1d2b",
  "ok": true,
  "text": "生成的正文…",
  "usage": { "inputTokens": 1820, "outputTokens": 963, "costUsd": 0.00312 },
  "steps": 1,
  "harnessName": "pi",
  "harnessVersion": "0.85.0",
  "toolCalls": []
}
```

失败：

```json
{
  "requestId": "5b8d4c3f9a0e1d2b",
  "ok": false,
  "text": null,
  "usage": { "inputTokens": 0, "outputTokens": 0, "costUsd": 0 },
  "steps": 0,
  "harnessName": "pi",
  "harnessVersion": "0.85.0",
  "errorCode": "PROVIDER_AUTH",
  "errorMessage": "DEEPSEEK_API_KEY not configured"
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `scene` | 仅用于 harness 侧日志与工具白名单，不改变执行语义 |
| `tools` | **工具名白名单**，非工具定义。空数组表示纯文本生成 |
| `maxSteps` | Agent 循环上限。纯生成为 1；拆解类需 > 1 |
| `thinking` | `off` / `minimal` / `low` / `medium` / `high` |
| `baseUrl` | OpenAI 兼容端点，Ollama / vLLM / 自建网关用 |
| `apiKeyEnv` | 环境变量名。harness 侧据此取密钥，Java 全程不接触密钥 |

错误码：

| errorCode | 含义 |
| --- | --- |
| `BAD_REQUEST` | 契约字段缺失或非法 |
| `MODEL_NOT_FOUND` | provider/model 在 harness 的模型表里不存在 |
| `PROVIDER_AUTH` | 密钥缺失或鉴权失败 |
| `PROVIDER_QUOTA` | 余额耗尽或配额用满。与限流同为 HTTP 429，但**不可重试**，必须单独分码 |
| `PROVIDER_RATE_LIMIT` | 上游限流，**唯一值得重试**的错误（指数退避 1s/4s/16s） |
| `PROVIDER_ERROR` | 上游其它错误 |
| `TOOL_ERROR` | 工具执行失败 |
| `TIMEOUT` | 超时 |
| `ABORTED` | 被取消 |

### 12.3 工具清单

Agent 侧内置工具，按场景通过 `tools` 白名单启用：

| 工具名 | 参数 | 作用 | 底层 |
| --- | --- | --- | --- |
| `fetch_video` | `{ url, browser? }` | 平台识别 + 尝试取件，失败返回录屏指引 | `skills/video-script-extract/scripts/fetch.py` |

| --- | --- | --- |

| `SCRIPT_DEAI` | `[]` | 1 |
| `SCRIPT_REWRITE` | `["check_script"]` | 6 |
| `VIDEO_EXTRACT` | `["fetch_video", "transcribe"]` | 8 |

## 13. 前端调用时序摘要

```
登录        POST /api/auth/sms/code → /api/auth/sms/login → 存 token
进入工作台   GET /api/options + GET /api/persona
向导过程     本地维护 sel；每步变化本地拼提示词预览
确认生成     POST /api/scripts/generate → { taskNo, accepted }
             → 跳文案库 → 每 2s GET /api/tasks/{taskNo}
             → status 终态后 GET /api/scripts 刷新列表
看详情       GET /api/scripts/{id}（含 breakdown）
洗稿         POST /api/rewrites → 轮询 → GET /api/rewrites/{id} → publish
我的         GET /api/auth/me + GET /api/credits + GET /api/credits/packs
```

## 14. 限流

| 接口 | 限制 |
| --- | --- |
| `POST /api/auth/sms/code` | 同手机号 60 秒 1 次、每日 10 次；同 IP 每小时 30 次 |
| `POST /api/scripts/generate` | 同用户每分钟 3 次；进行中任务上限 2 个 |
| `POST /api/teardowns` | 同用户每分钟 2 次 |
| `POST /api/rewrites` | 同用户每分钟 2 次 |
| `POST /api/files` | 同用户每小时 20 次 |

超限返回 429 与 `Retry-After`。
