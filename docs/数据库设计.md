## 1. 设计约定

| 约定 | 说明 |
| --- | --- |
| 主键 | `BIGINT UNSIGNED AUTO_INCREMENT`，命名 `id` |
| 时间 | `DATETIME`，`created_at` 默认 `CURRENT_TIMESTAMP`，`updated_at` 带 `ON UPDATE` |
| 软删除 | `deleted TINYINT NOT NULL DEFAULT 0`，MyBatis-Plus 逻辑删除 |
| 金额 | 一律以**分**存储（`INT UNSIGNED`），展示层转元 |
| 额度 | 以**条**存储（`INT`），可为负数流水 |
| 成本 | LLM 成本用 `DECIMAL(12,6)` 存美元，避免浮点误差 |
| 枚举 | 用 `VARCHAR` + 注释穷举，不用 MySQL `ENUM`（改值不用改表） |
| 变长文本 | 口播正文 `MEDIUMTEXT`；结构化中间产物用 `JSON` |
| 字数 | 中文字数按去空白后的码点数统计，存 `INT` |

## 4. 表结构

### 4.1 `sv_user` 用户

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED | PK | |
| phone | VARCHAR(20) | UK（可空） | 手机号，跨端唯一身份 |
| open_id | VARCHAR(64) | UK（可空） | 微信 openid |
| union_id | VARCHAR(64) | | 微信 unionid |
| nickname | VARCHAR(64) | NOT NULL | 展示名；手机号登录默认脱敏号 `138****1234` |
| avatar | VARCHAR(255) | | 头像 URL 或 emoji |
| via | VARCHAR(16) | NOT NULL | 首次注册渠道：`wechat` / `phone` |
| status | TINYINT | NOT NULL DEFAULT 1 | 1 正常 / 0 停用 |
| free_granted | TINYINT | NOT NULL DEFAULT 0 | 是否已发过新人赠额，保证只赠一次 |
| last_login_at | DATETIME | | |
| created_at / updated_at / deleted | | | |

索引：`uk_phone(phone)`、`uk_open_id(open_id)`。

**归并规则**：微信登录若返回手机号且该手机号已存在，则认领该用户并回填 `open_id`；反之短信登录时若手机号已有 `open_id` 记录，直接复用同一行。

### 4.2 `sv_sms_code` 短信验证码

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGINT UNSIGNED | PK |
| phone | VARCHAR(20) | NOT NULL |
| code | VARCHAR(8) | NOT NULL，6 位数字 |
| expire_at | DATETIME | NOT NULL，签发 +5 分钟 |
| used | TINYINT | NOT NULL DEFAULT 0 |
| send_ip | VARCHAR(64) | 风控用 |
| created_at | DATETIME | |

索引：`idx_phone_created(phone, created_at)`。

校验取该手机号最新一条未使用且未过期的记录；校验通过置 `used=1`。60 秒重发间隔与每日上限由 `created_at` 计数实现。

### 4.11 `sv_credit_account` 额度账户

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGINT UNSIGNED | PK |
| user_id | BIGINT UNSIGNED | UK |
| balance | INT | NOT NULL DEFAULT 0，可用额度 |
| hold | INT | NOT NULL DEFAULT 0，预扣中（任务未终态） |
| total_granted | INT | NOT NULL DEFAULT 0，累计赠送 |
| total_recharged | INT | NOT NULL DEFAULT 0，累计充值 |
| total_consumed | INT | NOT NULL DEFAULT 0，累计消耗 |
| version | INT | NOT NULL DEFAULT 0，乐观锁 |
| created_at / updated_at | | |

索引：`uk_user(user_id)`。

**可用额度 = `balance`**，`hold` 只做展示与对账；扣减用条件更新保证不超扣：

```sql
UPDATE sv_credit_account
   SET balance = balance - #{n}, hold = hold + #{n}, version = version + 1
 WHERE user_id = #{uid} AND balance >= #{n};
```

受影响行数为 0 即额度不足，直接拒绝。

## 7. 数据安全

| 项 | 做法 |
| --- | --- |
| 密钥 | 只存环境变量名，不存值；`api_key_env` 字段本身不敏感 |
| 手机号 | 列表展示脱敏 `138****1234`，详情仅本人可见 |
| 素材 | 录屏、音频、转写产物存私有目录，鉴权回源，不进公共 CDN |
| 越权 | 所有业务查询强制 `user_id` 条件；删除先校验归属 |
| 删除 | 一律软删除，保留审计链路 |
| 留痕 | 不记录 prompt 与生成正文到日志表 |
