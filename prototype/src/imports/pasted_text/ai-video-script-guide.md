接下来说一说选题逻辑和步骤，

第一步，从“选题类型”选择一个选项，比如“转化类选题”

第二步，从“选题来源”的角度，选一个选项。比如“行业热点借势融合”

第三步，"玩转 25 宫格圈"：

	内圈可以去链接外圈，进行一个配对，然后引出一个话题。

	比如25宫格内圈的"AI就业"去链接25宫格中圈的"薪资"，就引出"AI岗位就业的薪资范围大概是多少"，这个方向的话题；

第四步，去套一个爆款元素句式，比如“荷尔蒙”，"AI岗位就业的薪资范围大概是多少" + “荷尔蒙” 就引出 “我一个朋友开法拉力撩正妹，原来他是做AI行业的”的选题

	eg. 当选题遇上“爆款元素”，会发生什么
		成本：如何快速瘦身 -> 宝妈产后三个月．肚子下不去如何快速瘦下来
		成本：如何搭建一个直播间 -> 花2000块如何搭建一个高清直播间
		头牌：夏日必备穿搭 -> 迪丽热巴同款夏日穿搭•速速get
		成本 + 奇葩：数码好物分享 -> 拼多多上的那些合理，但有病的数码产品
		荷尔蒙：买车应该注意什么 -> 预算20w买什么车最适合撩到高分妹
		最差：教你如何点外卖不踩坑 -> 挑战吃附近评分最低的外卖
		反差：周未去做美甲 -> 周末带奶奶去美甲店做美甲
		怀旧：爆火的歌曲 -> 1996年金曲，贯穿了一代人的青春

第五步，生成标题，注意，选题不等于就是标题！
	1）选题是概念、话题领域，是贯穿全文的内容主线，是你看到了，你大概就能够知道他要说什么，至少知道它的范围和方向
	2）标题是为了去吸引眼球的，所以你想要怎么取都可以，它甚至可以和文案没有半点关系，是让你看到了，但是你并不能确定他要说什么，但你会产生好奇，从而停留下来去看一看

	eg.
	选题：能够快速减脂不反弹的10种方法
	标题：一个星期我从100 斤掉到了90斤，妈呀，我怎么这么牛？

第六步，生成脚本文案
	选择一个脚本类型，比如“话题共鸣”类。注意，如果是批量生成，则随机配比的概率为 4:1:3:2，即 痛点科普是4，Vlog 叙事为1，聊天纪实是3，话题共鸣是2

----Tips 1
黄金三秒勾子，详解：
黄金3秒钩子，留住用户注意力
1、实景开场
	摈弃空洞念白，用真实的工作场景打破距离感，让用户瞬间代入，潜意识里认为“这是真实发生的，对我有参考价值”，从而自然停留
2、共情提问
	开口直击用户内心的困惑与焦虑，产生“这说的就是我”的强烈共鸣，情绪上被击中后，用户会迫切知道解决方案
3、反常识观点
	利用反常识或颠覆性观点制造悬念和认知冲突，激发用户的好奇心和求知欲，让用户忍不住想知道“为什么”和“是什么”

【关键心法】：钩子的本质是在第一秒就建立“相关性”。无论是展示真场景、提出灵魂拷问，还是抛出反常识观点，核心都是让用户觉得“这与我有关，我能从中获得价值”，从而放弃划走的动作；

避坑预警：拒绝“标题党”式虚假钩子
钩子必须与内容强相关，切勿为流量制造噱头。虚假开场会引发用户的被欺骗感，导致完播率断崖式下跌，甚至降低账号在平台的推荐权重，得不偿失

中段分层钩子•全程拉住用户
1、节奏排布规律：
	严格遵循“10-15秒法则”，在内容中段周期性预埋悬念或信息反转。利用短视频的碎片化观看特性，不断制造“小期待”，打破用户的视觉疲劳阈值，从生理节奏上杜绝中途跳出的可能；
2、情绪共鸣：
	精准狙击职场内卷、薪资落差、成长迷茫等青年核心痛点。通过“场景化反问”瞬间拉满代入感，让用户产生“这说的就是我”的强烈共鸣，用情绪共振替代枯燥的说教，牢牢锁住注意力；
3、价值锚点
	紧扣 “就业保障、行业前景、稳定发展”三大核心诉求。用真实数据和可预期的结果打消家长的决策顾虑，将内容价值与孩子的未来发展深度绑定，打造无法划走的“利益驱动型；

----Tips 4
文案优化，新手两大核心通病修正
通病1：什么内容都根塞进去
拿转化型文案举例：很多人觉得自家产品很好，十几个卖点全部堆进文案。
结果用户看完毫无感觉，直接划走。
问题不是文案长，是信息过载，用户记不住。

解决方案：分清重点与非重点
比如你有5个卖点：
70%的篇幅重点讲1-2个核心卖点，其余卖点简单一笔带过。
只有用户听进去，才会产生认可，才有后续转化

*通病2：书面化太重，缺少“人感”
短视频文案是用来口播讲出来的，不是书面阅读。
书面感太强，念出来就会一板一眼，没有情绪，没有真实感，打动不了人。
短视频用户大多碎片化刷视频：地铁、上班摸鱼，注意力很涣散，文案一定要好懂

实操检验小技巧：
写好的文案，讲给完全不懂这个领域的人听，甚至讲给爷爷奶奶听。
如果他们都听得懂，你的文案才算及格。
越是通俗易懂的内容，传播性越强，越容易拿到流量。
有句话说得好：越是“高级”的，反而离人民群众距离越远

	干货做饵，合规筛选高意向

	既符合平台合规要求，又能精准筛选出有真实需求的潜在客户

	场景植入，弱化转化目的性
