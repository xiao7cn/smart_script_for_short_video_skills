# 第七步：去 AI 味

AI 味太重，文案一眼假。第六步产出的初稿必须经过这一步才能交付。

---

## 执行方式

把第六步的正文原样复制一份，再加上下面这段提示词，作为一次独立的重写（不要和写作合并成一步——同一次生成里既写又改，模型会保留自己的表达习惯）：

```
请全面化身为顶级语言风格编辑、真人表达校准师与AI痕迹清除专家。

在不改变原文事实、核心观点和重要信息的前提下，对全文进行深度重写。

删除空洞开场、正确但没有信息量的废话、机械连接词、过度完整的排比、重复总结、虚假的情绪升华和教科书式表达。

重新调整句子长短、停顿节奏、观点顺序和用词密度，加入符合语境的真实细节、自然转折和明确立场允许存在克制的不完美。

禁止推砌网络热词、故意口语化、编造个人经历、增加原文没有的事实，以及把文章改成另一种模板化文风
```

重写后必须核对：字数仍不低于 500 字，事实与数据没有被改动，软引导仍在结尾且未使用禁用词。若重写后跌破 500 字，补充具体细节而不是补回废话。

> 还是那句：AI 产出的内容仅供参考。即便这样，也要自行再朗读后适当修改。

---

## AI 味的典型症状（自查用）

| 症状 | 例子 | 改法 |
| --- | --- | --- |
| 空洞开场 | "在当今这个飞速发展的时代……" | 直接进钩子，删掉整句 |
| 机械连接词 | "首先""其次""综上所述""值得注意的是" | 换成口语的"再说一个""还有个事儿""所以说" |
| 过度完整的排比 | 三句结构完全对齐、字数也对齐 | 保留结构对齐，打乱字数与节奏 |
| 重复总结 | 结尾把前面每一点又说一遍 | 只留一个结论，其余删掉 |
| 虚假情绪升华 | "让我们一起拥抱 AI 时代，创造属于自己的精彩人生！" | 换成一句克制的真心话 |
| 教科书式表达 | "该岗位具备较强的就业竞争力与发展潜力" | "这个岗位现在真挺缺人，工资也给得起" |
| 万能修饰词 | "赋能""闭环""底层逻辑""核心竞争力" | 换成具体动作和具体名词 |
| 数字整齐得可疑 | "薪资 20K，缺口 100 万，增长 50%" | 给区间、给来源，或改成"十几到二十几个 K" |

## 附：写作阶段的参考提示词

以下是原始参考提示词，写作时可用于校准语气与产出要求。SKILL.md 的工作流已经把它的要求拆进各步骤（人设配置、选题、脚本结构、500 字下限、大白话、只要纯文案不要画面），因此**不需要**再原样使用；当用户明确要求"就按这个提示词来"时才直接套用。

```
你现在是一名资深的短视频文案写手，你会在写文案之前，搜罗分析网上相关选题的一些高赞视频做分析和参考，并根据我的行业赛道，以及不同类型的脚本文案结构来撰写短视频文案。

现在开始，我每给你一个行业赛道，选题以及脚本文案结构，你就用这样的方法来出一个爆款文案，所有文案最终不能低于 500 字。文案要清晰有条理，用大白话说，不要专业感很强的词语，我只要纯文案，不需要有画面。

我的行业是 AI 培训，我是这个行业的职业规划师，这次的选题是：《XXXXXX》，脚本文案结构是：开头抛痛点（包括黄金 3 秒钩子）+ 中间讲干货 + 结尾软引导。
```
