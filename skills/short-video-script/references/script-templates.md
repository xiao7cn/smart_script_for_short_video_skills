# 四类万能脚本 · 结构与范文

四类脚本覆盖了短视频账号的全部功能位。批量生成时的随机配比为 **痛点科普 : Vlog叙事 : 聊天纪实 : 话题共鸣 = 4 : 1 : 3 : 2**（由 `scripts/pick.py` 按最大余数法分配，不必自己估算）。

| 脚本类型 | 结构公式 | 用户看完的心理 |
| --- | --- | --- |
| 痛点科普 | 开头抛痛点 + 中间讲干货 + 结尾软引导 | 白嫖你 |
| Vlog 叙事 | 开场引入 + 片段拼接 + 结尾感悟 | 了解你 |
| 聊天纪实 | 场景引入 + 对话片段 + 观点总结 | 信任你 |
| 话题共鸣 | 抛出话题 + 表达观点 + 引导评论 | 喜欢你 |

---

## 1. 痛点科普（白嫖你）

**结构公式**：开头抛痛点 + 中间讲干货 + 结尾软引导

专为知识转化打造，精准戳中用户焦虑。用硬核干货建立信任壁垒，最后以解决方案自然承接，是实现高效变现的核心框架。

写作要点：

- 干货必须可执行、可验证——具体岗位名、具体薪资区间、具体学习周期、具体门槛，不能停在"要提升自己"这种正确的废话。
- 采用编号并列（第一个方向、第二个方向……），每段结构对齐但字数不必对齐。
- 至少标出一个"最推荐"，给用户省掉决策成本。
- 结尾用干货资产做软引导，不叫卖（见 `writing-craft.md` 的"无痕软引流"）。

---

## 2. Vlog 叙事（了解你）

**结构公式**：开场引入 + 片段拼接 + 结尾感悟

适合日常工作生活记录，以沉浸式镜头语言串联碎片化场景，弱化刻意感，通过结尾的情绪升华或个人感悟，提升内容温度与代入感。

写作要点：

- 只写口播词，画面靠场景词自然带出（"刚从客户公司出来""这会儿刚下高铁"），不写分镜表。
- 片段之间用时间或地点做转场，别用"接下来我们来看"这种书面连接词。
- 结尾感悟要克制，一句真心话胜过三句排比。
- Vlog 里的经历必须是配置里 `persona_position` 支撑得住的真实类型；素材不足时向用户索取当天的真实片段，不要编造个人经历。

---

## 3. 聊天纪实（信任你）

**结构公式**：场景引入 + 对话片段 + 观点总结

还原真实沟通场景，以实景对话增强内容可信度；剔除多余铺垫，直抛核心观点；兼顾故事质感与专业说服力。

写作要点：

- 用"他说……我说……"的直接引语，对话要短，像真人抢话那样有来回。
- 咨询者的信息给到可辨识但不可识别的程度（年龄、学历、专业、现薪），这既是隐私底线，也是可信度来源。
- 观点总结只讲 1 个结论，不要在结尾补第二个观点。

---

## 4. 话题共鸣（喜欢你）

**结构公式**：抛出话题 + 表达观点 + 引导评论

流量撬动核心公式：用争议/共情话题做钩子，抛出鲜明观点站稳立场，结尾抛出开放提问带动互动，拉高平台推荐权重。

写作要点：

- 立场必须单一且明确，骑墙的观点没有互动。
- 争议要冲行为和选择，不冲人群和身份，不制造对立。
- 结尾的提问必须是开放题且答案有分歧，"你怎么看"太空——问"你会选哪个"。

---

## 范文：痛点科普

以下为完整范文，用于校准语感、段落颗粒度与信息密度。段落标记（黄金 3 秒·痛点引入 / 核心讲解·解决方案 / 价值升华·行动号召）是写作骨架的提示，**最终交付给用户的正文不要保留这些括号标记**。

**脚本类型**：痛点科普
**结构公式**：开头抛痛点 + 中间讲干货 + 结尾软引导，从"我好烦"到"有救了"

---

（黄金 3 秒·痛点引入）

如果你计算机毕业找不到工作，先别着急否定自己，更别盲目转行。

我花了一周时间分析 26 年的最新招聘行情，梳理了下 AI 风口下 4 个真实可行的高薪就业方向。
不管你是想稳就业还是想冲高薪，都能找到适合自己的方向。如果你学历不错，我最推荐第 4 个。

（核心讲解·解决方案）

第一个方向：AI 测试
AI 行业的持续爆发直接带火了这个岗位，竞争小还不内卷。
学历要求不高，专科也能做，零基础学 4-6 个月就能上岗。
应届生的薪资普遍在 10-15K，不用啃复杂的代码，特别适合细心耐心的女生，入门简单就业稳。

第二个方向：AI 运维
这个岗位不容易被 AI 取代，核心工作还得靠人，经验越久越吃香，完全不用担心 35 岁的危机。
门槛不高，大专就能入行。重点看实操，代码基础弱的同学优先选它。
应届生普遍薪资在 8-15K，比传统的运维高不少。不过要提醒一下，这个工作出差比较多，辛苦一些。

第三个方向：AI 应用开发工程师
有 Java 基础想拿高薪的优先选这个方向。
现在企业最缺的是能把大模型落地到业务上的人，不用深挖底层算法。
集中学 3 个月就能达标，薪资比传统开发岗高 30%-40%。
普通本科就可以冲，岗位缺口非常大，不用跟硕士卷底层算法，把大模型做好业务落地，照样拿高薪。

第四个方向：大模型开发工程师（最后一个重点推荐）
适合学历不错，愿意深耕技术的同学。
主要做大模型微调、RAG、向量数据库、Agent 智能体开发。
应届生普遍 18-30K，工作两三年，年薪可以冲到 50-80 万。
天花板很高，但是对学习能力有要求，数学基础不能太差。

（价值升华·行动号召）

最后我想说，26 年求职难度升级，找工作不仅需要你选对方向，还需要你有好技术好项目。
我能做的就是把这四个方向的学习路线图免费送你，帮你更顺利的拿 offer。

---

### 从范文里要抄走的三件事

1. **信息密度**：每个方向都给齐了「门槛 + 学习周期 + 薪资区间 + 适合谁 + 代价」，没有一句是空的。
2. **诚实的负面信息**：「出差比较多，辛苦一些」「数学基础不能太差」——主动说缺点，可信度反而更高。
3. **软引导的位置**：整篇只在最后一句给资料，且给的是干货本身，不是"私信我了解课程"。

### 不要从范文里抄走的

段落数量和"四个方向"的形式。范文恰好是并列结构，是因为它的选题适合并列。换成"聊天纪实"或"话题共鸣"时，硬套编号并列会让文案变得机械——按各自的结构公式来。
