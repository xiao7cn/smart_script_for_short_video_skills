# 选题坐标系：类型 · 来源 · 25 宫格 · 爆款元素

选题参数的完整清单与判定标准。`scripts/pick.py` 负责抽取组合，本文件负责解释每个值背后的意图，以及如何把参数组合"翻译"成一个真正的选题。

---

## 一、选题类型（决定这条内容为什么而拍）

| 类型 | 内涵 | 判定标准 |
| --- | --- | --- |
| 转化类 | 聚焦 AI 转行前景、岗位解析、培训避坑等刚需话题，直击用户学习；承接流量效果强，快速筛选高意向潜在学员，是账号变现的核心 | 看完能不能筛出高意向的人 |
| 破圈类 | 围绕职场内卷、赛道抉择、成长感悟等普适话题，跳出垂直领域局限依托情绪共鸣快速拉高内容曝光、打破圈层壁垒，持续为账号注入新流量，不断扩容潜在用户池 | 不懂这个行业的人会不会也想看 |
| 家长类 | 从子女职业规划、核心技能价值、就业稳定性多维切入，精准戳中家长对孩子未来发展的核心顾虑；立足家庭视角建立信任、消解用户防御心理，从决策端深度撬动报名意向 | 决策人是家长而不是孩子本人 |

写作影响：转化类必须落到具体岗位/薪资/路径；破圈类要压住专业术语、放大情绪；家长类的主语要从"你"切换到"孩子"，并用数据消解风险顾虑。

## 二、选题来源（决定内容素材从哪来）

| 来源 | 内涵 | 落地动作 |
| --- | --- | --- |
| 客户咨询高频提问 | 客户高频提问，就是最好的选题方向。直面这些真实诉求，精准击中用户需求，产出既有共鸣又利于转化的内容 | 从配置里的 `audience_needs` 挑 1 条作为选题内核，正文里要出现"最近有个同学问我……"这类真实感锚点 |
| 对标爆款拆解 | 拆解同赛道高赞内容的底层逻辑与用户偏好，通过"换视角、换话术、换案例"，进行差异化二次创作，拒绝简单搬运，打造有新意的爆款平替 | **需要用户额外提供对标视频 URL**，见下方"对标拆解"小节 |
| 评论私信需求挖掘 | 深挖评论区、私信中的用户疑问、吐槽与建议。这些反馈是高互动选题的金矿，精准匹配潜在受众的好奇点、焦虑点与求知欲 | 需要用户粘贴真实评论/私信原文；没有素材时向用户索取，不要凭空编造用户留言 |
| 行业热点借势融合 | 紧跟行业新闻、职场趋势与社会热点，结合自身领域输出专业观点与深度解读，借势平台流量风口，让内容自带曝光度与传播力 | 联网检索近期行业新闻/招聘趋势，取 1 个具体事件做引子；检索不可用时向用户索要热点，不要编造新闻和数据 |

### 对标拆解（source = 对标爆款拆解）

找对标不等于抄文案。你直接抄、简单改写，永远做不过原版。别人的思路已经固化在你的脑海，二创怎么改都会觉得别扭、不满意。

正确对标做法：拆解同选题/同话题对标账号的文案结构

- 看对方是怎么论证观点、输出内容的
- 挖掘有没有你想不到的角度、观点
- 借鉴这套思考逻辑，完全原创输出属于你自己的内容

通过对标拆解，搭建完整属于你的文案逻辑架构。

执行时：交给配套的 `video-script-extract` skill，它支持抖音、快手、小红书、微信视频号，负责取件、转写成带时间戳的口播稿，并输出结构拆解表（钩子怎么起、分几段论证、每段用什么证据、中段钩子在第几秒、结尾怎么引导）与可复用的逻辑框架。拿到框架后回到本流程的步骤 2 原创。

该 skill 未安装时，请用户直接粘贴对标文案原文，再自行完成拆解。两种路径都禁止逐句改写——换词、换语序、换案例都算改写，只允许复用抽象出的结构骨架。

## 三、25 宫格：内圈 × 中圈 × 外圈

25 宫格是选题的坐标系：内圈是账号锚点（1 个），中圈是业务领域切面（8 个），外圈是人群与场景（16 个）。默认值见 `config/persona.example.yaml` 的 `matrix` 段，可按账号自行替换。

- **内圈**：AI就业
- **中圈**：求职 / 面试 / 专业 / 薪资 / 晋升 / 岗位·职业 / 培训 / AIGC
- **外圈**：毕业生 / 求职者 / 待转行 / 专·本科生 / 机构 / 考公·编 / 失业·被裁 / 文·理科生 / 不同专业 / 普通人 / 找对象 / 大厂 / 投资成本 / 发展前景 / 职场 / 保障

### 配对方法

内圈去链接中圈或外圈，配对后引出一个话题方向。

> 内圈"AI就业" × 中圈"薪资" → "AI岗位就业的薪资范围大概是多少"

三圈同时配对时，把外圈当作限定条件：

> "AI就业" × "薪资" × "失业·被裁" → "35 岁被裁之后转 AI 岗，薪资能回到原来的水平吗"

配对产物是**话题方向**，还不是选题，更不是标题。它的作用是把话题框死在一个具体范围里，避免写成万金油。

## 四、爆款元素句式（把话题方向变成选题）

| 元素 | 句式参考 |
| --- | --- |
| 成本 | 便宜又有面子的 / 十分之一的时间·金钱 / 花大钱干的 / xxx 如何贪小便宜 / xx 如何偷懒 |
| 人群 | 身价十个亿的 / 兜里一分钱没有的 / 想要（）但不具备条件的 / 因为（）导致现在可愁了 |
| 奇葩 | 外行人不知道的 / 脑回路有病的 / 黑心内幕操作 |
| 头牌 | xx 电视剧里出现的 / 生意最好的 / 最贵的·好评最多的 / 明星·名人·名校·名企 |
| 怀旧 | 古代的·具体朝代的 / 20 年前的 / 如果能重来一次 / 历史风潮盘点 |
| 反差 | 反向操作 / 身份反差 / 古今·中外·南北·品牌·穷富 |
| 最差 | 最难吃最难用的 / 最没面子的·样子最丑的 / 拼多多 9 块 9 的 / 差评最多·贬值最多 |
| 荷尔蒙 | 好找对象的 / 魅力变强的 |

### 当选题遇上"爆款元素"，会发生什么

| 元素 | 平淡话题 | 套上元素后的选题 |
| --- | --- | --- |
| 成本 | 如何快速瘦身 | 宝妈产后三个月，肚子下不去如何快速瘦下来 |
| 成本 | 如何搭建一个直播间 | 花 2000 块如何搭建一个高清直播间 |
| 头牌 | 夏日必备穿搭 | 迪丽热巴同款夏日穿搭，速速 get |
| 成本 + 奇葩 | 数码好物分享 | 拼多多上的那些合理，但有病的数码产品 |
| 荷尔蒙 | 买车应该注意什么 | 预算 20w 买什么车最适合撩到高分妹 |
| 最差 | 教你如何点外卖不踩坑 | 挑战吃附近评分最低的外卖 |
| 反差 | 周末去做美甲 | 周末带奶奶去美甲店做美甲 |
| 怀旧 | 爆火的歌曲 | 1996 年金曲，贯穿了一代人的青春 |

本项目场景的示例：

> "AI岗位就业的薪资范围大概是多少" + 荷尔蒙 → "我一个朋友开法拉利撩正妹，原来他是做 AI 行业的"

**红线**：元素只用来包装呈现角度，不能改变事实。套完之后必须回头检查——正文能不能真的把这个角度讲实？讲不实就换元素，别硬套（否则就变成了下面要禁止的虚假钩子）。

## 五、选题 ≠ 标题

- **选题**是概念、话题领域，是贯穿全文的内容主线，是你看到了，你大概就能够知道他要说什么，至少知道它的范围和方向。
- **标题**是为了去吸引眼球的，所以你想要怎么取都可以，它甚至可以和文案没有半点关系，是让你看到了，但是你并不能确定他要说什么，但你会产生好奇，从而停留下来去看一看。

示例：

> 选题：能够快速减脂不反弹的 10 种方法
> 标题：一个星期我从 100 斤掉到了 90 斤，妈呀，我怎么这么牛？

标题的自由度高，但仍受一条约束：不能让用户看完正文产生被欺骗感（见 `writing-craft.md` 的"避坑预警"）。标题可以不透露结论，但不能承诺正文给不了的东西。
