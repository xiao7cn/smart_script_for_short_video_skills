# 结构拆解模板

拆解的目的不是拿到文案，是拿到**对方的思考逻辑**。拆完你应该能回答一个问题：如果这个话题给我，我会怎么组织？

---

## 拆解表模板

### 1. 黄金 3 秒

| 项 | 内容 |
| --- | --- |
| 钩子类型 | 实景开场 / 共情提问 / 反常识观点 / 其他 |
| 原句 | |
| 实际占用 | 第 0 到第 X 秒 |
| 建立相关性的方式 | 对方用什么让观众觉得"这跟我有关" |
| 判定 | 有效 / 无效（虚假钩子、与正文脱节都算无效） |

### 2. 结构骨架

| 时间段 | 这一段在干什么 | 原句摘要 | 用了什么证据 |
| --- | --- | --- | --- |
| 0-8s | 抛痛点 | | 无 |
| 8-25s | 给方向一 | | 薪资区间 |
| … | | | |

"这一段在干什么"要写功能而不是内容——抛痛点、立信任、给方案、埋钩子、转折、收口。

### 3. 中段钩子

| 秒数 | 钩子类型 | 原句 | 距上一个钩子 |
| --- | --- | --- | --- |

钩子类型取：悬念预埋 / 信息反转 / 情绪共鸣 / 价值锚点 / 排比递进。

统计一行：**共 N 个钩子，平均间隔 X 秒**。对照 10-15 秒法则，超过 20 秒没有钩子的段落标出来——那通常是对方的掉播率位置，也是你能做得更好的地方。

### 4. 论证方式

| 项 | 内容 |
| --- | --- |
| 证据类型 | 数据 / 案例 / 亲身经历 / 对比 / 权威背书 / 纯观点 |
| 信息密度 | 每个论点给齐了哪几个要素（门槛、周期、薪资、适合谁、代价） |
| 有没有说代价 | 主动讲缺点的地方会显著提升可信度，记下来 |
| 数据可信度 | 给的是区间还是精确值，有没有出处 |
| 重点分配 | 是否 70% 篇幅只讲 1-2 个核心点，还是平铺直叙全塞 |

### 5. 结尾引导

| 项 | 内容 |
| --- | --- |
| 类型 | 分享式 / 资料式 / 场景式 / 硬广叫卖 |
| 原句 | |
| 占全文比例 | |
| 给的是什么 | 干货资产 / 私信入口 / 课程 / 什么都没给 |

### 6. 反推参数（对接 short-video-script）

| 参数 | 判断 | 依据 |
| --- | --- | --- |
| 选题类型 | 转化类 / 破圈类 / 家长类 | |
| 25 宫格坐标 | 内圈 × 中圈 × 外圈 | |
| 爆款元素句式 | 成本 / 人群 / 奇葩 / 头牌 / 怀旧 / 反差 / 最差 / 荷尔蒙 / 未使用 | |
| 脚本类型 | 痛点科普 / Vlog叙事 / 聊天纪实 / 话题共鸣 | |
| 选题与标题的关系 | 标题是否透露了结论 | |

这一步是两个 skill 的接口。填完就能直接把坐标喂给 `short-video-script`，换人群、换角度做原创。

### 7. 可原创复用的逻辑框架

把结构抽象成不含具体内容的骨架，每条只写功能：

```
1. 用一个具体的人的具体处境开场，不讲道理
2. 先否掉观众最可能的错误做法，建立"我懂你"
3. 给 N 个并列方向，每个方向给齐门槛+周期+薪资+适合谁
4. 在最后一个方向前埋"重点推荐"钩子
5. 收口时把资产给出去，不要索取
```

骨架可以照搬，内容必须全部原创。

### 8. 对方想到而我们没想到的角度

逐条写，并说明为什么有效。这是拆解里最值钱的部分——如果这一栏是空的，说明这条视频不值得拆。

### 9. 不要学的地方

爆款不等于全对。常见的不该学：贩卖焦虑、承诺兑现不了的结果（保证就业、包分配）、编造数据、制造人群对立、虚假钩子。列出来，避免在原创时无意识继承。

## 示例：拆解一条痛点科普

以 `short-video-script/references/script-templates.md` 里的痛点科普范文为对象，演示颗粒度。

**1. 黄金 3 秒**：共情提问型。原句"如果你计算机毕业找不到工作，先别着急否定自己，更别盲目转行"。占 0-6 秒。相关性建立方式是直接点明身份（计算机毕业+找不到工作），命中即停留。判定有效——正文确实给了方向，没有脱节。

**2. 结构骨架**：抛痛点（0-6s）→ 立信任并预告结构（6-20s，"花了一周时间分析"+"最推荐第 4 个"）→ 四个方向并列（20-150s）→ 收口给资产（150-165s）。

**3. 中段钩子**：3 个。第 18 秒"如果你学历不错，我最推荐第 4 个"（悬念预埋，把观众留到最后）；每个方向的起始句构成排比递进；第 120 秒"最后一个重点推荐"（二次确认悬念）。平均间隔约 35 秒——**偏长了**，中段第二、三个方向之间有 40 多秒没有钩子，这是可以做得比原版更好的地方。

**4. 论证方式**：数据+对比。每个方向给齐了门槛、周期、薪资区间、适合谁、代价，信息密度很高。主动说代价两处（"出差比较多，辛苦一些""数学基础不能太差"）。薪资给的是区间不是精确值。重点分配上是平铺四个方向，没有做 70/30 取舍——这是它的弱点。

**5. 结尾引导**：资料式。原句"把这四个方向的学习路线图免费送你"。占比约 8%。给的是干货资产，没有索取动作。

**6. 反推参数**：转化类 / AI就业 × 岗位·职业 × 毕业生 / 未使用爆款元素句式 / 痛点科普。标题透露了结论（"4 个高薪方向"），属于选题即标题的保守做法，可以在标题上做得更勾人。

**7. 逻辑框架**：见上方骨架示例。

**8. 对方想到而我们没想到的**：把"专科也能做""代码基础弱优先选它"这种**学历/能力分层**写进每个方向，让不同基础的观众都能自我归位——这比单纯罗列岗位有效得多，也自然筛出了高意向人群。

**9. 不要学的地方**：四个方向平铺导致重点涣散；薪资数字集中出现容易触发"画大饼"的抵触感，可以拆散到各段。
